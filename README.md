# hordes

Red is horde  
Blue is city  
Green is just grass  

You must destroy the horde and save the cities!  
Use the booms.  You only get so many.

Drop the booms, in order. Hit the horde. Miss the cities.

## Play

Tap a cell to drop a boom. Hold to see the footprint, release to drop, slide off to cancel.

Booms blows up horde but also city!

RESET puts the wave back. A clear wave opens the next card.
